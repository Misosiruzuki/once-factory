# Once Factory — 一度きりの工場

Minecraft 1.20.1 Forge Mod

## コンセプト
機械には寿命がある。効率で永遠に最適化する土俵は存在しない。
使い切ったら壊し、次の工場を設計せよ。

## 現在の実装（縦スライス）

### 粉砕機 (Crusher)
- GUI付き（入力スロット / 出力スロット）
- 処理中に寿命が少しずつ減る
- 寿命比率で見た目が3段階変化
  - 0 (新品): 通常テクスチャ
  - 1 (使用中): 使用感テクスチャ
  - 2 (危険): 危険テクスチャ
- 寿命が尽きると「壊れた機械」に置換

### 壊れた機械
- 解体すると「寿命の記憶」が1個得られる

### 寿命の記憶
- ツールチップで効果を表示
- （次の実装）クラフト時に使うと初期寿命ボーナス

### 対応レシピ（ハードコード）
- 鉄/金/銅/石炭/ダイヤモンド鉱石 → 対応する原石 or アイテム増量
- 丸石 → 砂利
- 砂利 → 砂

## 遊び方
1. 粉砕機をクラフトして設置
2. 右クリックでGUIを開く
3. 鉱石を入れて処理させる
4. 寿命が減っていくのを観察
5. 死んだら壊して「寿命の記憶」を回収
6. 次の工場を設計する
