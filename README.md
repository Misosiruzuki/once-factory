# Once Factory — 一度きりの工場

**Minecraft 1.20.1 · Forge 47.4.10**

機械には寿命がある。  
効率で永遠に最適化する土俵は存在しない。  
使い切ったら壊し、**次の工場を設計せよ。**

---

## コンセプト

既存の工業Modは「アップグレードして永遠に使える」方向が主流です。  
Once Factory はその土俵自体をなくします。

- 機械は**処理中に寿命を消費**する
- 寿命が尽きると「壊れた機械」になる
- 壊すと **寿命の記憶** が得られる
- 延命より「次の工場を設計する」ことが正しい遊び方

## 現在の内容（v0.1.0）

### 粉砕機 (Crusher)
| 機能 | 内容 |
|------|------|
| GUI | 入力1スロット / 出力1スロット |
| 寿命 | 処理中に少しずつ減少 |
| 見た目 | 3段階劣化（新品 → 使用中 → 危険） |
| 死亡時 | 壊れた機械に置換 |

### 壊れた機械
- 解体すると **寿命の記憶** が1個ドロップ

### 寿命の記憶
- 死んだ機械から得られる特殊アイテム
- （予定）クラフト時に使うと初期寿命ボーナス

### 対応レシピ
- 鉄・金・銅・石炭・ダイヤモンド鉱石 → 原石/増量
- 丸石 → 砂利
- 砂利 → 砂

### クラフト
```
鉄インゴット ×6 + 滑らかな石 ×3 → 粉砕機
```

## セットアップ（開発）

```bash
# JDK 17+ が必要
./gradlew genIntellijRuns
./gradlew runClient
```

ビルド:

```bash
./gradlew build
# → build/libs/examplemod-1.0.0.jar
```
